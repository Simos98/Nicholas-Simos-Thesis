# Honours Thesis - Leveraging Web Scraping and AI Agents for Scam Detection on Social Media

This repository contains my Software Engineering Honours Thesis and accompanying presentation, exploring the use of AI agents and web scraping techniques to detect and track evolving scam activities across social media and communication platforms.
